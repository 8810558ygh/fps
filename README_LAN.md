# 局域网团队战

## Electron 桌面版（推荐）

桌面版是独立应用，不需要安装 Node.js，也不需要浏览器和服务器地址。房主和加入者
都运行同一个安装版或便携版。

1. 房主启动应用，进入“局域网多人”，点击“创建房间”。
2. 房主房间页会显示带房间码的“局域网邀请网址”，点击“复制网址”发送给朋友。
3. 朋友在同一个局域网内用浏览器打开网址，会自动进入当前房间；也可以启动应用后输入 5 位房间码加入。
4. 双方选择队伍并准备，由房主开始比赛。

邀请网址类似：

```text
http://192.168.1.100:8090/?lanRoom=ABCDE
```

该网址由房主电脑提供，不是 GitHub Pages 地址。朋友只打开个人主页或 `/fps/` 静态页面时，浏览器仍无法自动发现房主电脑。

安装版使用正常的 Windows 安装向导，可以选择游戏安装位置，不会强制安装到
系统盘。桌面快捷方式默认创建。

应用启动时会自动运行内置房间服务器，并通过 UDP 自动发现局域网房间。加入者
不需要输入 IP 地址；所有玩家最终连接房主的服务器，因此延迟基准一致。

- 必须处在同一个局域网，不能使用开启了“访客隔离”的公共 Wi-Fi。
- 房主必须保持应用开启；房主关闭应用后房间会断开。
- 首次启动时 Windows 防火墙可能要求允许“双雄对决”访问专用网络，请允许。
- 便携版没有购买代码签名证书，Windows SmartScreen 可能显示未知发布者。
- 便携版每次启动会先解压到临时目录，首次打开会比之后稍慢，这是正常现象。

## 玩家资料与战绩

首次启动桌面版时，游戏会在 `双雄对决.exe` 同目录自动创建：

```text
双雄对决资料\
├─ profile.json   玩家 ID 和个人标识
├─ matches.json   最近的比赛战绩
└─ 说明.txt
```

例如安装版位于 `D:\Double Hero\heroes-duel-lan\双雄对决.exe`，资料目录就是：

```text
D:\Double Hero\heroes-duel-lan\双雄对决资料
```

便携版会使用你实际双击的便携 EXE 所在目录。旧版本保存在“文档\双雄对决”的
ID 和战绩会在首次启动新版时自动复制到新目录；旧文件夹会保留作为备份。

进入“设置 → 玩家资料”可以：

- 修改最多 20 个字符的玩家 ID，联机大厅和聊天会使用新 ID。
- 查看比赛数、胜场、K/D、击杀、死亡、总伤害和最近比赛。
- 一键打开本机资料文件夹。

每场局域网比赛结束后，客户端会保存胜负、蓝红比分、地图、队伍、击杀、死亡、
伤害和比赛时长。最多保留最近 500 场。移动游戏文件夹时请同时移动
“双雄对决资料”；卸载游戏前建议先备份。资料只保存在当前游戏目录，浏览器模式
和桌面版不会跨设备同步。

## 自动性能

“设置 → 画面 / 性能”中默认开启“自动性能优化”。进入人机、在线、局域网或生存
对战时，游戏会提前切换到简化渲染配置，减少开局时的着色器和阴影卡顿：

- 所有对战模式最高使用 65% 的 3D 渲染比例。
- 所有对战模式关闭实时阴影，并将特效密度限制在 55%。
- 远端玩家和人机 AI 保留完整人物模型与全部命中部位，只把第三人称枪械换成
  低成本单件枪模型。
- 远端物理影子体按位置同步频率更新，不再每个渲染帧重复计算。
- WebGL 请求使用高性能显卡，并优先复用同一台房主服务器。

性能较弱的电脑可以在对战时通过右上角 FPS 信息确认帧率。如果仍不足 60 FPS，
可将基础画质设为“性能优先”，并把 3D 分辨率调为 50%～65%。如果关闭“自动性能
优化”，则会完整使用玩家自己的阴影和分辨率设置。

开发时可在项目目录运行：

```powershell
npm install
npm run electron
```

生成便携版或安装版：

```powershell
npm run dist:all
```

如果只需要其中一种：

```powershell
npm run dist
npm run dist:installer
```

生成后的 EXE 位于 `dist/`。

## Node.js / 浏览器模式

最简单的方法：双击项目目录里的：

```text
启动局域网服务器.bat
```

启动成功后会自动打开本机游戏页面，并显示局域网访问地址。关闭这个命令行窗口就会停止服务器。

也可以在项目目录运行：

```powershell
npm install
npm start
```

默认端口为 `8090`。服务器启动后会输出类似：

```text
本机: http://127.0.0.1:8090
局域网: http://192.168.1.100:8090
```

同一局域网内的玩家在浏览器中打开“局域网”地址，进入大厅后点击“局域网多人”。
此模式仍需要房主运行 Node.js 服务器，并让大家访问房主的局域网地址。

如果 8090 端口已被占用，可以换一个端口：

```powershell
$env:PORT="8091"
npm start
```

首次启动时 Windows 防火墙可能询问是否允许 Node.js 接收局域网连接，需要允许专用网络访问。

## 规则

- 蓝队和红队各最多 5 人，人数不需要相等。
- 所有在线玩家准备后，由房主开始比赛。
- 每回合 5 秒准备时间。
- 回合内阵亡不复活，可以观战仍在存活的队友。
- 一队全部阵亡后，另一队获得 1 个回合分。
- 双方同时全灭时该回合为平局。
- 先获得 10 个回合分的队伍获胜。
- 默认关闭友军伤害。

## 回合交火报告

服务器按“攻击者 → 受击者”记录每个回合的头部、身体、腿部和油桶伤害，以及双方
的击杀、死亡关系：

- 玩家阵亡时立即显示本回合交火报告。
- 阵亡报告会保留到下一回合准备阶段结束。
- 回合结束时仍存活的玩家，在下一回合准备阶段显示刚结束回合的报告。
- 正式开战时自动关闭并清除上一回合报告。
- 每个与本地玩家产生伤害交互的对手单独复用一张“人物伤害”卡片，结构与
  人机报告相同：左侧输出总伤害、中间头/身/腿部位明细、右侧承受总伤害。
- 有油桶伤害时，为该对手额外复用一张“环境伤害”卡片。
- 不额外显示存活状态或双方比分。

## 近战判定

刀使用近距离扇形范围判定，而不是只命中一个精确射线目标：

- 轻刀基础伤害 50，重刀基础伤害 75，背刺伤害翻倍。
- 一次挥刀会命中正前方约 52°、2.35 米内所有无遮挡敌人或僵尸。
- 每名目标分别计算背刺、护甲和伤害。
- 墙壁会阻挡近战判定，队友不会被刀命中。
- 局域网服务器会一次接收全部命中目标，并在全部目标结算后判断回合胜负。
- 人机 AI、在线 1v1、局域网团队战和生存模式共用同一套扇形判定。

## 断线与重连

- 房主退出游戏时，服务器通知所有玩家关闭当前房间并自动返回大厅。若房主进程直接
  消失，客户端在短暂重连失败后也会退出到大厅。
- 比赛开始后，普通新玩家不能再加入；只有服务器在开局时记录的玩家 IP 可以重连。
- 非房主掉线时，服务器保留其队伍、座位、生命状态和本局 K/D，但该玩家从存活人数、
  人物显示和受击目标中暂时移除。
- Tab 面板中的掉线玩家显示为灰色，效果与阵亡行一致。
- 同一 IP 重连成功后恢复原队伍、原座位和本局统计。
- 只有整局结束、房主返回房间准备阶段后，仍未重连的旧座位才会被释放，新玩家才能
  加入。

## 网络设计

- Node.js WebSocket 局域网服务器。
- 服务器权威管理房间、队伍、回合计时、生命、伤害、淘汰和比分。
- 客户端到服务器状态上报约 30Hz。
- 服务器状态快照约 30Hz，所有客户端使用同一快照 tick。
- 远端玩家使用独立插值目标，避免画面抖动。
- 本地移动即时响应，远端位置平滑插值。

## 公网部署

GitHub Pages 只能托管静态文件，不能运行房间服务器。推荐在 Render、Railway 或支持
Node.js WebSocket 的云服务器上部署整个项目。

项目已包含 `render.yaml`：

```text
Build Command: npm install --omit=dev
Start Command: npm start
```

部署成功后，所有玩家只访问云服务提供的网址。进入大厅后直接创建或加入房间，
不需要输入服务器地址。免费实例可能会休眠，若需要随时立即建房，应选择不会休眠的实例。

Koyeb 可直接识别项目根目录的 `Dockerfile`：

```text
Builder: Dockerfile
Service port: 8090
Health check path: /
```
